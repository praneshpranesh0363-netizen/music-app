2

3

4
User selects a song.

8
The user stays on the same page throughout.
📖 Project Theory

This project is a simple music streaming and download application. Users can search for their favourite songs, play them without any ads, and download the songs in MP3 format. The download happens in the background and the user can access the saved files from their device. The application is designed to keep the user on the same page, without redirecting to any other website.

⭐ Key Features
• Search songs and browse playlists
• Play music directly on the same page
• Download songs (with background process)
• Save as MP3 file
• Access downloaded files from device storage
• No redirection to other websites
